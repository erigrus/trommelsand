# Trommelsand

Procedural music video for **Trommelsand** by **FUZZAN**.

[Watch the video page](https://erigrus.github.io/trommelsand/)

The page renders the video live in WebGL with the song. Use the resolution selector if playback is slow.

GitHub Pages builds and publishes automatically from `main` using `.github/workflows/pages.yml`.
The workflow installs the renderer dependencies, downloads the walker model, and publishes `video/dist/`.

For local setup, rendering and project status, see [the handoff guide](docs/04-handoff.md).
